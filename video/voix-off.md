# Voix off — texte ElevenLabs

Généré avec la voix « Jade — Customer Service », stabilité 50 %, similarité 75 % (« v4 » d'après le nom du
fichier). Les balises entre crochets demandent un modèle qui les comprend (Eleven v3 ou plus récent) : les modèles
plus anciens les liraient à voix haute.

Après une nouvelle génération : remplacer `public/voix-off.mp3`, puis mettre à jour les repères de
`src/voix-off.ts` (début et fin de chaque paragraphe) ; la vidéo se recale toute seule.
